# Tasbeeh

Downloads for the Tasbeeh Android app, an offline tasbeeh counter.

**[Download the latest version](https://github.com/muhammadmunaf/tasbeeh-releases/releases/latest)**: on your phone, tap the `.apk` file under Assets, open it, and allow "install unknown apps" if asked.

Once installed, the app checks here for new versions and offers to update itself.
